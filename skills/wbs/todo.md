기간 26/6/1~8/31

1. 통합검색 고도화
- 검색어 자동완성
- 검색결과 필터링
- 사용자 쿼리 이력 수집 및 템플릿화
- 검색 결과에 Query 검색 결과 제공
- 상세 조회 시 Query Template 및 공출연 정보 제공

| Task | 목적 | 구현 기능 |
|------|------|-----------|
| 검색어 자동완성 구축 | 사용자의 검색 입력 속도 및 검색 정확도 향상 | Prefix 기반 자동완성, 동의어 추천, 유사 업무 키워드 추천, Metadata 기반 추천, 인기 검색어 추천 |
| 자동완성 인덱스 구축 | 검색 추천 품질 향상 및 빠른 응답 제공 | OpenSearch Suggest Index 설계, 추천어 사전 구축, 검색 로그 기반 추천어 생성 |
| 검색 결과 필터링 기능 구축 | 검색 결과를 조건별로 빠르게 축소하여 탐색 효율 향상 | Catalog 필터, 데이터 유형 필터, 도메인 필터, Tag 필터, 정렬 기능 |

| Query History 수집 기능 구축 | 실제 데이터 활용 패턴 자산화 | SQL 실행 이력 저장, 사용자/시간/테이블 정보 저장 |
| SQL Parsing 기능 구축 | Query 구조 분석 및 재사용 가능한 정보 추출 | 사용 테이블 추출, 컬럼 추출, JOIN 분석, WHERE 조건 분석 |
| Query Template 생성 기능 구축 | 반복 사용되는 Query를 재사용 가능한 형태로 제공 | 변수 치환, SQL 일반화, Template 생성 |
| Query Template 분류 기능 구축 | Query 탐색성과 추천 품질 향상 | Query 유형 분류, 업무 유형 분류, Tag 기반 분류 |
| 인기 Query 분석 기능 구축 | 자주 사용하는 Query 우선 제공 | 실행 빈도 분석, 사용자 수 분석, 최근 사용량 분석 |
| 검색 결과 Query 연계 기능 구축 | 검색 결과에서 바로 활용 가능한 SQL 제공 | 검색 키워드 기반 Query 검색, Query Preview 제공 |
| Query 연관도 분석 기능 구축 | 검색 정확도 향상 | 키워드-테이블-컬럼-Query 연관도 계산 |
| Query 상세 조회 기능 구축 | Query 이해도 및 활용성 향상 | 전체 SQL 조회, 설명 조회, 사용 테이블 조회 |
| 테이블 상세 추천 Query 기능 구축 | 데이터 활용 진입 장벽 감소 | 관련 Query Template 5개 추천 |
| Query 목적 설명 기능 구축 | 사용자의 Query 이해 지원 | Query 사용 목적 설명, 업무 설명 제공 |
| 공출연 테이블 분석 기능 구축 | 연관 데이터 탐색 지원 | JOIN 빈도 분석, 동시 사용 테이블 분석 |
| 공출연 테이블 추천 기능 구축 | 데이터 확장 탐색 지원 | 연관 테이블 추천, 클릭 기반 탐색 연계 |
| 검색 품질 개선 체계 구축 | 검색 정확도 및 사용자 만족도 향상 | 검색 로그 분석, 추천 품질 개선, Ranking 개선 |
| 검색 API 연계 개발 | 검색 서비스 통합 제공 | 자동완성 API 연계, 검색 API 연계, Query 검색 API 연계 |

| 검색 UI 개선 | 사용자 탐색 경험 향상 | 자동완성 UI, 필터 UI, Query 추천 UI, 상세 조회 UI |
| 통합 테스트 및 품질 검증 | 기능 안정성 및 검색 품질 확보 | 검색 테스트, 추천 정확도 테스트, 성능 테스트 |
